# Laskuri

Ahlsell-pihan seikkailuajastin. Countdown, jossa pipopäinen hahmo kävelee kohti BOS-5-autoa Ahlsellin pihalla. Valaistus seuraa kellonaikaa.

Sivu: https://uffeta.github.io/Laskuri/

## Käyttö

1. Anna tapahtumalle nimi, päivämäärä ja kellonaika.
2. Paina **Käynnistä matka**.
3. Laskuri näyttää jäljellä olevan ajan. Napauta laskuria tai paina **M**, niin näkymä vaihtuu päivien ja pelkkien tuntien välillä.
4. **Koko näyttö** sopii jaettavaksi. **Jaa linkki** kopioi osoitteen.

Pikavalinnat: +30 s testi, +5 min ja huomenna klo 16:00.
